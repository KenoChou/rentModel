# 模型推理服务平台前端原型

这是一个使用 React 编写的前端原型，用于展示模型推理服务平台的核心控制台页面。当前阶段只包含静态交互原型，不包含后端模型推理或 MCP 服务实现。

## 功能范围

- 平台总览：在线模型、今日调用量、平均延迟、MCP Tools 等关键指标。
- 模型调试：选择模型、编辑推理输入、展示所选模型的业务场景和延迟信息。
- MCP 服务：展示 `list_models`、`infer`、`get_model_metrics` 等工具发布形态。
- 模型注册：以表格方式呈现模型名称、提供方、业务场景、QPS 和状态。

## 本地运行

```bash
npm run dev
```

服务启动后访问：

```text
http://127.0.0.1:5173/
```

## 技术说明

- 使用 React 19 ESM CDN 模块，避免在原型阶段引入打包链路。
- 使用原生 CSS 完成仪表盘布局、卡片、表格、状态标签和响应式样式。
- `npm run check` 会对 `src/main.js` 执行 Node.js 语法检查。
